# Contributing

Open an issue describing the operator problem, platform, expected behavior, and sanitized evidence. Do not attach credentials or private infrastructure reports.

Keep collection read-only and explicit. Add tests for unavailable evidence and threshold boundaries. Preserve JSON schema compatibility or document a version change. Run `python -m unittest discover -s tests -v` before a pull request. Update the specification and user docs when supported behavior changes.

Use English for code, documentation, issues, and pull requests. Do not claim hardware support based only on mocks. Licensing is pending the owner's selection; discuss contributions with the maintainer before submitting substantial work.
